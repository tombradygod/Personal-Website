# Rushil Shah - Personal Portfolio

This folder is the complete website source. Upload its contents to one GitHub
repository; do not upload `node_modules` or any build folder.

## Run locally

1. Install Node.js 22 or newer.
2. Run `npm install`.
3. Run `npm run dev`.

## Verify a deployment

Run `npm run build`.

The website content lives in `app/`, while the research paper and social image
live in `public/`.
